# Why Use PyTrendy?

- **Financial markets**: Identify bullish/bearish trends in stock or crypto price series.
- **Economics**: Detect macroeconomic trend shifts in indicators like inflation or GDP.
- **IoT / Sensor data**: Spot anomalies and sustained changes in signals.
- **Scientific data**: Analyze experimental measurements for upward/downward trends.
- **General analytics**: Any dataset with sequential time-based values can benefit.

    === "Quick Method"


=== "Custom Pipeline"

    ```python
    df = process_signals(df, value_col='price')
    segments = get_segments(df)
    segments = refine_segments(df, 'price', segments, {})
    ```

=== "With Padding"

    ```python
    results = pt.detect_trends(
        df, date_col='date', value_col='price',
        method_params={'is_abrupt_padded': True, 'abrupt_padding': 28}
    )
    ```

    📦 MkDocs Material Pro Tips

    Enable These Features in mkdocs.yml:

    theme:
  features:
    - content.code.copy          # Copy button on code blocks
    - content.tabs.link          # Linked tabs
    - navigation.top             # Back to top button
    - navigation.tracking        # URL updates with scroll

markdown_extensions:
  - pymdownx.superfences:
      custom_fences:
        - name: mermaid
          class: mermaid
          format: !!python/name:pymdownx.superfences.fence_code_format
  - pymdownx.tabbed:
      alternate_style: true
  - pymdownx.details            # For ??? collapsible
  - attr_list                   # For custom attributes
  - md_in_html                  # For HTML in markdown
